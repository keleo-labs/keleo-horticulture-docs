# <i class="fa-solid fa-smog" style="font-size:20px"></i> Carbon Footprint Report

[TOC]


Quantified greenhouse gas emissions for a horticultural operation or product.

## Levels of Detail

### 1. Emission Inventory

Total GHG emissions disaggregated by Scope 1, 2, and 3.

**Checklist:**

- [ ] Emissions calculated in CO2 equivalents: Emissions calculated in CO2 equivalents for defined reporting period.
- [ ] Scope categories disaggregated: Scope 1, 2, and material Scope 3 categories disaggregated.
- [ ] Emission factors sourced: Emission factors sourced from recognised databases.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Measured](../concerns/biological-systems/sustainability-environmental-stewardship.md#1-measured)

**Developed by:**

- [Measure and Report Environmental Footprint](../activities/production-operations/manage-resources-waste-streams/measure-and-report-environmental-footprint.md)

### 2. Product Carbon Footprint

Cradle-to-gate LCA using PAS 2050-1 methodology.

**Checklist:**

- [ ] System boundary defined: System boundary and allocation rules defined per PAS 2050-1.
- [ ] Horticultural emission sources addressed: Horticultural-specific emission sources addressed (CHP, crop rotation, soil carbon).
- [ ] Uncertainty analysis documented: Uncertainty analysis documented alongside results.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Reduced](../concerns/biological-systems/sustainability-environmental-stewardship.md#2-reduced)

**Developed by:**

- [Measure and Report Environmental Footprint](../activities/production-operations/manage-resources-waste-streams/measure-and-report-environmental-footprint.md)

### 3. Carbon Balance Sheet

Emissions integrated with sequestration credits and offsets.

**Checklist:**

- [ ] Sequestration credits quantified: Sequestration credits from soil carbon, biomass, and biochar quantified.
- [ ] Offset programmes documented: Verified offset or insetting programmes documented.
- [ ] Net carbon position determined: Net carbon position determined demonstrating balance or net negative status.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Neutral](../concerns/biological-systems/sustainability-environmental-stewardship.md#3-neutral)

**Developed by:**

- [Measure and Report Environmental Footprint](../activities/production-operations/manage-resources-waste-streams/measure-and-report-environmental-footprint.md)

### 4. Hybrid LCA Report

Full hybrid analysis capturing upstream supply chain emissions.

**Checklist:**

- [ ] Hybrid methodology captures additional emissions: Hybrid methodology captures emissions missed by process-based LCA.
- [ ] Comparative analysis documented: Comparative analysis against conventional LCA results documented.
- [ ] Supply chain hotspots identified: Supply chain emission hotspots identified for targeted reduction.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Positive](../concerns/biological-systems/sustainability-environmental-stewardship.md#4-positive)

**Developed by:**

- [Measure and Report Environmental Footprint](../activities/production-operations/manage-resources-waste-streams/measure-and-report-environmental-footprint.md)
