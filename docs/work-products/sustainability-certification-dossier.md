# <i class="fa-solid fa-certificate" style="font-size:20px"></i> Sustainability Certification Dossier

[TOC]


Compiled evidence demonstrating compliance with environmental certification standards.

## Levels of Detail

### 1. Self-Assessment Record

Completed self-assessment identifying compliance gaps.

**Checklist:**

- [ ] **Certification requirements assessed**: Requirements of target certification scheme assessed point by point, using established criteria and documented methodology with results validated by qualified practitioners.
- [ ] **Compliance gaps identified**: Areas of compliance and gaps requiring remediation identified by internal or external auditors.
- [ ] **Remediation timeline**: Complete documentation with clearly defined scope, methodology, results, and recommendations following professional standards and regulatory requirements.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Measured](../concerns/biological-systems/sustainability-environmental-stewardship.md#1-measured)

**Developed by:**

- [Measure and Report Environmental Footprint](../activities/production-operations/manage-resources-waste-streams/measure-and-report-environmental-footprint.md)

### 2. Audit-Ready Evidence Pack

Structured portfolio prepared for external auditor review.

**Checklist:**

- [ ] **Evidence organised by requirement**: Policies, procedures, and monitoring records organised by certification requirement, with systematic data collection, trend analysis, and documented response protocols for threshold exceedances.
- [ ] **Improvement plans**: Complete documentation with clearly defined scope, methodology, results, and recommendations following professional standards and regulatory requirements.
- [ ] **Evidence portfolio prepared**: Complete documentation with clearly defined scope, methodology, results, and recommendations following professional standards and regulatory requirements.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Reduced](../concerns/biological-systems/sustainability-environmental-stewardship.md#2-reduced)

**Developed by:**

- [Implement Peat-Free Growing Media Transition](../activities/biological-systems/establish-manage-growing-environments/implement-peat-free-growing-media-transition.md)

### 3. Multi-Scheme Compliance File

Dossier demonstrating simultaneous multi-standard compliance.

**Checklist:**

- [ ] **Multiple standards cross-referenced**: LEAF Marque, MPS-GAP, GLOBALG.A.P, and BNG requirements cross-referenced by internal or external auditors.
- [ ] **Overlapping requirements mapped**: Overlapping requirements mapped to eliminate evidence duplication by internal or external auditors.
- [ ] **Continuous audit readiness**: Complete documentation with clearly defined scope, methodology, results, and recommendations following professional standards and regulatory requirements.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Systemic](../concerns/biological-systems/sustainability-environmental-stewardship.md#6-systemic)

**Developed by:**
