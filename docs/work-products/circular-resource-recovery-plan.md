# Circular Resource Recovery Plan

[TOC]


Documented strategies for closing material and nutrient loops.

## Levels of Detail

### 1. Recovery Inventory

Identification of waste streams amenable to recovery with volumes.

**Checklist:**

- [ ] Waste streams identified: Waste streams including nutrient solutions, growing media, and crop residues identified.
- [ ] Volumes documented: Estimated volumes for each waste stream documented.
- [ ] Recovery potential assessed: Recovery potential assessed for each stream.

**Contributes to:**

- [Water-Energy-Nutrient Nexus](../concerns/production-operations/resource-management.md) — [Conserved](../concerns/production-operations/resource-management.md#3-conserved)

### 2. Recovery Process Design

Recovery technologies specified with process flow diagrams.

**Checklist:**

- [ ] Recovery technologies specified: Recovery technologies (phosphorus precipitation, UV-C, composting) specified per stream.
- [ ] Process flow diagrams documented: Process flow diagrams document material transformation pathways.
- [ ] Quality specifications defined: Quality specifications for recovered materials defined.

**Contributes to:**

- [Water-Energy-Nutrient Nexus](../concerns/production-operations/resource-management.md) — [Circular](../concerns/production-operations/resource-management.md#5-circular)

**Developed by:**

- [Implement Circular Resource Recovery](../activities/production-operations/manage-resources-waste-streams/implement-circular-resource-recovery.md)

### 3. Validated Circular System

Measured recovery rates with lifecycle assessment comparisons.

**Checklist:**

- [ ] Recovery rates documented: Measured recovery rates and substitution ratios for virgin materials documented.
- [ ] LCA comparisons completed: Lifecycle assessment comparisons against linear alternatives completed.
- [ ] Regulatory compliance maintained: Regulatory compliance documentation for recovered material use maintained.

**Contributes to:**

- [Water-Energy-Nutrient Nexus](../concerns/production-operations/resource-management.md) — [Regenerative](../concerns/production-operations/resource-management.md#6-regenerative)

**Developed by:**

- [Verify Regenerative Resource Outcomes](../activities/production-operations/manage-resources-waste-streams/verify-regenerative-resource-outcomes.md)
