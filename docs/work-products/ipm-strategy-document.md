# <i class="fa-solid fa-shield-virus" style="font-size:20px"></i> IPM Plan

[TOC]


Integrated plan coordinating pest, disease, and weed management tactics.

## Levels of Detail

### 1. Pest and Disease Register

Target organisms with identification and intervention options.

**Checklist:**

- [ ] Target organisms listed: All target organisms listed with identification features documented.
- [ ] Monitoring methods specified: Monitoring methods specified for each organism type.
- [ ] Intervention options catalogued: Approved intervention options catalogued per target organism.

**Contributes to:**

- [IPM](../concerns/biological-systems/plant-protection.md) — [Monitored](../concerns/biological-systems/plant-protection.md#1-monitored)

**Developed by:**

- [Perform Pest and Disease Scouting](../activities/biological-systems/protect-plants-ecosystems/perform-pest-and-disease-scouting.md)

### 2. Threshold-Based Action Plan

Decision framework with economic injury levels and escalation.

**Checklist:**

- [ ] EILs documented: Economic injury levels documented for each significant pest species.
- [ ] Action thresholds specify triggers: Action thresholds specify population density triggering intervention.
- [ ] Intervention sequences defined: Preferred intervention sequences and escalation criteria defined.
- [ ] Resistance monitoring baselines established: Resistance monitoring baselines established for active substances.

**Contributes to:**

- [IPM](../concerns/biological-systems/plant-protection.md) — [Thresholds Established](../concerns/biological-systems/plant-protection.md#2-thresholds-established)

**Developed by:**

- [Establish Action Thresholds for Pest Management](../activities/biological-systems/protect-plants-ecosystems/establish-action-thresholds-for-pest-management.md)

### 3. Integrated Management System

Comprehensive strategy integrating biological, cultural, and chemical tactics.

**Checklist:**

- [ ] Biocontrol schedules integrated: Biological control deployment schedules integrated with cultural practices.
- [ ] Chemical use justified with rotation plans: Chemical use justification records maintained with resistance rotation plans.
- [ ] Pollinator risk mitigated: Pollinator risk mitigation measures documented for all applications.
- [ ] Annual programme unified: Annual programme unifies prevention, monitoring, and intervention tactics.

**Contributes to:**

- [IPM](../concerns/biological-systems/plant-protection.md) — [Integrated](../concerns/biological-systems/plant-protection.md#5-integrated)
- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Reduced](../concerns/biological-systems/sustainability-environmental-stewardship.md#2-reduced)

**Developed by:**

- [Deploy Biological Control Agents](../activities/biological-systems/protect-plants-ecosystems/deploy-biological-control-agents.md)
- [Establish Action Thresholds for Pest Management](../activities/biological-systems/protect-plants-ecosystems/establish-action-thresholds-for-pest-management.md)
- [Manage Resistance in Pest Populations](../activities/biological-systems/protect-plants-ecosystems/manage-resistance-in-pest-populations.md)

### 4. Ecological Management Framework

Landscape-scale plan with conservation biocontrol habitat design.

**Checklist:**

- [ ] Conservation habitat designed at landscape scale: Conservation biocontrol habitat designed at landscape scale.
- [ ] Pollinator corridor mapping included: Pollinator corridor mapping and beneficial arthropod monitoring included.
- [ ] Agroecosystem outcome evaluation conducted: Agroecosystem-level outcome evaluation conducted beyond field boundaries.

**Contributes to:**

- [IPM](../concerns/biological-systems/plant-protection.md) — [Ecological](../concerns/biological-systems/plant-protection.md#6-ecological)
- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Positive](../concerns/biological-systems/sustainability-environmental-stewardship.md#4-positive)
