# <i class="fa-solid fa-frog" style="font-size:20px"></i> Biodiversity Assessment Report

[TOC]


Evaluation of ecological condition and biodiversity outcomes on managed land.

## Levels of Detail

### 1. Species Inventory

Catalogue of observed species compiled through surveys.

**Checklist:**

- [ ] **Species catalogued across taxa**: Plant, invertebrate, bird, and mammal species catalogued.
- [ ] **Standardised survey methods applied**: Standardised survey methods applied for each taxonomic group.
- [ ] **Survey timing aligned seasonally**: Survey timing aligned with seasonal activity patterns.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Measured](../concerns/biological-systems/sustainability-environmental-stewardship.md#1-measured)
- [Biosecurity](../concerns/biological-systems/biosecurity-ecosystem-health.md) — [Surveilled](../concerns/biological-systems/biosecurity-ecosystem-health.md#1-surveilled)

**Developed by:**

- [BNG Assessment](../activities/production-operations/manage-resources-waste-streams/conduct-biodiversity-net-gain-assessment.md)

### 2. Habitat Condition Assessment

Scored assessment using Biodiversity Metric or equivalent.

**Checklist:**

- [ ] **Habitat types mapped and scored**: Habitat types mapped with extent and condition scored.
- [ ] **Biodiversity Metric applied**: Biodiversity Metric applied for BNG baseline calculation.
- [ ] **Connectivity assessed**: Connectivity and strategic significance assessed per methodology.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Positive](../concerns/biological-systems/sustainability-environmental-stewardship.md#4-positive)

**Developed by:**

- [Design and Establish Pollinator Habitat](../activities/biological-systems/protect-plants-ecosystems/design-and-establish-pollinator-habitat.md)
- [BNG Assessment](../activities/production-operations/manage-resources-waste-streams/conduct-biodiversity-net-gain-assessment.md)

### 3. Net Gain Verification

Report demonstrating required percentage gain is achieved.

**Checklist:**

- [ ] **10% biodiversity gain demonstrated**: Minimum 10% biodiversity gain demonstrated using statutory methodology.
- [ ] **30-year maintenance secured**: Thirty-year maintenance mechanisms contractually secured.
- [ ] **Monitoring schedules defined**: Monitoring schedules defined for ongoing compliance verification.

**Contributes to:**

- [Environmental Sustainability](../concerns/biological-systems/sustainability-environmental-stewardship.md) — [Regenerative](../concerns/biological-systems/sustainability-environmental-stewardship.md#5-regenerative)

**Developed by:**

- [Design and Establish Pollinator Habitat](../activities/biological-systems/protect-plants-ecosystems/design-and-establish-pollinator-habitat.md)
- [BNG Assessment](../activities/production-operations/manage-resources-waste-streams/conduct-biodiversity-net-gain-assessment.md)
