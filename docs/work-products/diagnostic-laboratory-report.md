# <i class="fa-solid fa-microscope" style="font-size:20px"></i> Diagnostic Laboratory Report

[TOC]


Confirmed identification of pests, pathogens, or physiological disorders.

## Levels of Detail

### 1. Field Test Result

Rapid diagnostic outcome from point-of-care testing.

**Checklist:**

- [ ] Target organism and result recorded: Target organism, test method, result, and confidence level recorded.
- [ ] Controls run alongside samples: Positive and negative controls run alongside diagnostic samples.
- [ ] Kit conditions verified: Kit storage conditions and expiry dates verified before use.

**Contributes to:**

- [Biosecurity](../concerns/biological-systems/biosecurity-ecosystem-health.md) — [Detected Early](../concerns/biological-systems/biosecurity-ecosystem-health.md#3-detected-early)
- [IPM](../concerns/biological-systems/plant-protection.md) — [Monitored](../concerns/biological-systems/plant-protection.md#1-monitored)

**Developed by:**

- [Conduct Rapid Field Diagnostics](../activities/biological-systems/protect-plants-ecosystems/conduct-rapid-field-diagnostics.md)

### 2. Laboratory Confirmation

Formal identification to species level using molecular methods.

**Checklist:**

- [ ] Species-level identification achieved: Organism identified to species level via morphological and molecular methods.
- [ ] EPPO protocols referenced: EPPO PM 7 diagnostic protocols referenced where applicable.
- [ ] Accredited laboratory report provided: Accredited laboratory provides formal diagnostic report.

**Contributes to:**

- [Biosecurity](../concerns/biological-systems/biosecurity-ecosystem-health.md) — [Detected Early](../concerns/biological-systems/biosecurity-ecosystem-health.md#3-detected-early)

**Developed by:**

- [Conduct Rapid Field Diagnostics](../activities/biological-systems/protect-plants-ecosystems/conduct-rapid-field-diagnostics.md)
- [Manage Resistance in Pest Populations](../activities/biological-systems/protect-plants-ecosystems/manage-resistance-in-pest-populations.md)

### 3. Epidemiological Investigation

Comprehensive report with source tracing and risk evaluation.

**Checklist:**

- [ ] Source tracing completed: Source tracing and pathway analysis completed for detected organism.
- [ ] Geographic spread assessed: Geographic spread assessment conducted across landscape context.
- [ ] Risk evaluation informs response: Risk evaluation informs containment response and statutory notification.

**Contributes to:**

- [Biosecurity](../concerns/biological-systems/biosecurity-ecosystem-health.md) — [Contained](../concerns/biological-systems/biosecurity-ecosystem-health.md#4-contained)
