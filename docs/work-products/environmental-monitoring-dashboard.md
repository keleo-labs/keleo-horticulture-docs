# <i class="fa-solid fa-chart-line" style="font-size:20px"></i> Environmental Monitoring Dashboard

[TOC]


Integrated display of real-time and historical environmental data.

## Levels of Detail

### 1. Parameter Log

Tabular record of manually captured environmental measurements.

**Checklist:**

- [ ] Key parameters measured: Temperature, humidity, light, and substrate moisture measured at defined points.
- [ ] Sampling methodology documented: Sampling frequency and measurement methodology documented.
- [ ] Data format supports analysis: Data recorded in format supporting retrospective analysis.

**Contributes to:**

- [Growing Environment](../concerns/biological-systems/growing-environment.md) — [Characterized](../concerns/biological-systems/growing-environment.md#1-characterized)

**Developed by:**

- [Monitor Root Zone and Aerial Environment](../activities/biological-systems/establish-manage-growing-environments/monitor-root-zone-and-aerial-environment.md)

### 2. Automated Data Stream

Continuously updated display from IoT sensor network feeds.

**Checklist:**

- [ ] Sensor networks transmit continuously: Sensor networks transmit root zone and aerial data continuously.
- [ ] Alert thresholds highlighted: Alert thresholds highlighted when values deviate from target ranges.
- [ ] Historical trends visualised: Historical time-series visualisation supports trend identification.
- [ ] Sensor calibration documented: Sensor calibration schedule documented with cross-validation records.

**Contributes to:**

- [Growing Environment](../concerns/biological-systems/growing-environment.md) — [Monitored](../concerns/biological-systems/growing-environment.md#4-monitored)

**Developed by:**

- [Monitor Root Zone and Aerial Environment](../activities/biological-systems/establish-manage-growing-environments/monitor-root-zone-and-aerial-environment.md)

### 3. Predictive Analytics Platform

System combining sensor data with forecast models and ML.

**Checklist:**

- [ ] Weather forecast integration enabled: Weather forecast integration enables proactive environmental management.
- [ ] Growth models predict deviations: Crop growth models predict environmental deviations before occurrence.
- [ ] ML algorithms recommend interventions: Machine learning algorithms recommend proactive management interventions.

**Contributes to:**

- [Growing Environment](../concerns/biological-systems/growing-environment.md) — [Predictively Managed](../concerns/biological-systems/growing-environment.md#6-predictively-managed)

**Developed by:**

- [Monitor Root Zone and Aerial Environment](../activities/biological-systems/establish-manage-growing-environments/monitor-root-zone-and-aerial-environment.md)
