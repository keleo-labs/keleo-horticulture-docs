# Deploy Biological Control Agents

[TOC]


Release predators, parasitoids, or microbial agents to suppress pest populations.

## How to Deploy Biological Control Agents

STAR narrative for biological control agent deployment.

1. Target pest populations exceed monitoring levels and require suppression through ecologically sustainable mechanisms prioritising biological agents over chemical intervention.
2. Select, quality-assure, deploy, and monitor biological control agents matched to target pest biology, environmental conditions, and growing system constraints.
3. Select agents considering host specificity and environmental tolerance; verify quality at receipt per IOBC guidelines; deploy at recommended rates with timing adjusted for local conditions; monitor establishment and pest response.
4. Pest populations suppressed through ecological mechanisms, chemical dependency reduced, natural enemy populations enhanced, and quality-assured biocontrol maintains efficacy standards.
