# Implement Peat-Free Growing Media Transition

[TOC]


Systematically replace peat-based substrates with sustainable alternatives.

## How to Implement Peat-Free Growing Media Transition

STAR narrative for peat-free substrate transition.

1. Peat extraction destroys irreplaceable carbon stores and biodiversity, with Defra policy targeting professional grower peat elimination by 2026, requiring systematic substrate transition across all crop types.
2. Implement phased peat replacement beginning with validated crop applications, documenting performance equivalence, cost impacts, and pathogen risks for each alternative substrate.
3. Audit current peat consumption, evaluate coir, wood fibre, biochar, and composted green waste alternatives through replicated crop trials, implement transition progressively, and document before-and-after performance data.
4. Peat consumption systematically reduced toward elimination, alternative substrates validated for each production stage, transition costs documented, and compliance with emerging regulatory requirements maintained.
