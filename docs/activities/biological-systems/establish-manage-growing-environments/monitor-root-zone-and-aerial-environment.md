# Monitor Root Zone and Aerial Environment

[TOC]


Capture real-time environmental data from growing system sensor networks.

## How to Monitor Root Zone and Aerial Environment

STAR narrative for environmental monitoring activities.

1. Growing environments exhibit spatial and temporal variability in root zone moisture, temperature, EC, pH, and aerial conditions that manual sampling cannot capture at sufficient resolution.
2. Deploy sensor networks providing continuous environmental data with automated alerting, trend visualisation, and calibration governance.
3. Install root zone and aerial sensors at representative positions, configure wireless data transmission to centralised platforms, set alert thresholds for deviation detection, and maintain calibration through scheduled reference checks.
4. Environmental conditions are continuously documented, deviations detected promptly, historical data supports predictive modelling, and sensor accuracy maintained through calibration governance.
