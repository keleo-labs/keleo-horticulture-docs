# <i class="fa-solid fa-gauge-high" style="font-size:20px"></i> Calibrate Sensor and Control Systems

[TOC]


Verify and adjust measurement and control accuracy against reference standards.

## Calibrate Sensor and Control Systems Technique

Technique guidance for systematic sensor calibration and validation.

1. Low-cost environmental sensors require structured calibration protocols to maintain data quality underpinning all management decisions.
2. Verify all sensors and control outputs against reference standards within documented accuracy tolerances.
3. Calibrate CO2 sensors against reference gas standards, verify LED spectral output against crop requirements, apply Kalman filters for multi-sensor data quality, and document all calibration records.
4. Verified sensor accuracy, calibrated control outputs, validated multi-sensor data quality, and complete auditable calibration records.

> See: [Giordano et al. (2024)](../../../references.md#giordano-et-al-2024)
