# Procure and Install Technical Equipment

[TOC]


Select, acquire, and deploy infrastructure meeting production requirements.

## Procure and Install Technical Equipment Technique

Technique guidance for compliant equipment procurement and installation.

1. Production system requires climate control, lighting, sensor, robotic, and fertigation equipment from multiple vendors.
2. Procure equipment compliant with EU Directive 2006/42/EC and install to safety standards with documented asset registration.
3. Define specifications, evaluate vendors, verify CE marking and ISO 12100 compliance, install equipment with calibration baselines, and archive installation documentation.
4. Installed, individually verified, and documented technical infrastructure with initial calibration baselines and complete asset registration.
