# BNG Assessment

[TOC]


Measure ecological condition and calculate biodiversity change using statutory methodology.

## How to Conduct Biodiversity Net Gain Assessment

STAR narrative for biodiversity net gain assessment.

1. The Environment Act 2021 mandates minimum 10% biodiversity net gain secured for 30 years, requiring systematic habitat assessment using Natural England's Biodiversity Metric.
2. Conduct baseline and post-intervention habitat surveys quantifying biodiversity value in habitat units, demonstrating statutory compliance, and defining long-term monitoring obligations.
3. Map all habitat types within assessment boundary; score condition against published criteria; calculate net change in biodiversity units using statutory Metric; define habitat management and monitoring plan; secure 30-year maintenance.
4. Biodiversity impact quantified using statutory methodology, 10% net gain compliance demonstrated, long-term maintenance secured, and monitoring frameworks ensure accountability for predicted outcomes.
