# Horticulture Foundations

Comprehensive horticultural practice framework integrating biological systems management, production technology operations, and professional governance for evidence-based, sustainable plant production.

Modern horticulture faces converging challenges: climate change threatens traditional growing systems, pest and disease pressures intensify, resource constraints demand efficiency, and regulatory requirements grow increasingly complex. Horticulture Foundations provides an integrated framework that connects biological understanding with production technology and professional governance.

Checkout out the [docs site](https://keleo-labs.github.io/keleo-horticulture-docs/)

## Practices

The framework spans three interconnected practices:

- **Biological Systems** — Evidence-based approaches to plant health, growing environments, pest management, biosecurity, and environmental sustainability.
- **Production Operations** — Systematic frameworks for production system design, technical infrastructure, resource management, and digital integration.
- **Professional Practice** — Business viability, regulatory compliance, workforce development, and stakeholder management.

By integrating these three practices, horticultural enterprises achieve measurable improvements in plant health outcomes, production efficiency, environmental sustainability, and professional standards — enabling progressive maturity from foundational compliance through to innovative, regenerative, and autonomous operations.

## Content Model

The framework is structured around six interconnected content types:

| Content Type | Description |
|---|---|
| **Concerns** | Aspects of practice that must be managed, each with a progression of maturity states |
| **Activities** | Practitioner tasks that progress concern states and produce work products |
| **Work Products** | Documents and records produced by activities, with levels of detail |
| **Patterns** | Multi-concern lifecycle progressions showing how concerns evolve together |
| **Personas** | Teams and roles grouped by functional area |
| **Competencies** | Skills with five-level proficiency scales |

## Local Development

The site is built with [MkDocs](https://www.mkdocs.org/) using the [Material for MkDocs](https://squidfundamentals.github.io/mkdocs-material/) theme.

```bash
mkdocs serve    # Start dev server at http://127.0.0.1:8000
mkdocs build    # Build static site to site/
```
